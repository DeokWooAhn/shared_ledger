# iOS Maestro CI

- 목표: Android와 같은 기본 Flow 세 개를 iOS 시뮬레이터에서도 CI로 실행한다.
- 범위: 기존 CI에 iOS job 추가, 시뮬레이터 선택·실행 스크립트, 실행 안내와 출시 계획. 앱 동작과 기존 필수 검사 이름은 유지한다.
- 검증: CI 문법·셸 문법·변경 경로 테스트, 고정 Flutter로 iOS 테스트 앱 빌드, 시뮬레이터에서 Flow 세 개 실행.
- 완료: 앱 관련 변경에서 Android·iOS smoke가 실행되고 각 결과를 보관한다. 출시 때 두 플랫폼의 Maestro 성공을 배포 조건으로 연결한다는 계획을 기록한다.
- 검증 결과: 고정 Flutter로 iOS 테스트 앱 빌드 성공. 연결된 실기기가 없어 iPhone 17 Pro(iOS 26.5) 시뮬레이터에서 새 CI 스크립트를 실행했고, 워밍업과 smoke 3/3이 통과했다. JUnit·스크린샷·앱 로그 저장과 로컬 Firebase 종료도 확인했다.
- 추가 검사: Flutter 포맷·분석·전체 테스트 760개, CI 보조 스크립트 테스트 15개, actionlint와 셸 문법 검사를 통과했다.
- 러너: 프로젝트의 Xcode 27 요구사항에 맞춰 GitHub 공식 `xcode-27` 호스팅 러너를 선택했다. 기기 이름이 바뀌면 설치된 최신 iPhone을 선택하는 동작을 테스트했다.
- 남은 확인: GitHub Actions의 실제 러너 실행은 푸시 후 확인한다. 출시 배포 관문은 현재 연결하지 않고 `docs/plan.md`에 출시 자동화 연결 조건으로 남겼다.
